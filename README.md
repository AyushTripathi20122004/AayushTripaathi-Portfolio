# Aayush Tripathi — Portfolio 🚀

A modern, interactive, and fully responsive **developer portfolio website** built with React.js and modern frontend technologies.

## 📌 About The Project

This is my personal portfolio website, designed and developed to showcase my **frontend development skills, projects, technologies, and experience**.

The website focuses on a modern user interface, smooth scrolling, interactive animations, responsive layouts, and engaging user experiences.

## ✨ Features

* ⚛️ Built with React.js
* 🎨 Styled using Tailwind CSS
* 🎬 Smooth animations with GSAP
* 🖱️ Smooth scrolling using Lenis
* 🖼️ Interactive sliders using Swiper.js
* 📱 Fully responsive design
* 💻 Modern and interactive UI
* ✨ Scroll-based animations and transitions
* 🚀 Deployed using GitHub Pages

## 🚀 Getting Started

Follow these steps to run the portfolio on your local machine.

### 1. Install Node.js

Make sure **Node.js** is installed on your computer.

Download Node.js from:

https://nodejs.org/

Check the installation:

```bash
node -v
```

Check npm:

```bash
npm -v
```

### 2. Clone the Repository

Open your terminal and run:

```bash
git clone https://github.com/ayushtripathi20122004/AayushTripaathi-Portfolio.git
```

### 3. Navigate to the Project

```bash
cd AayushTripaathi-Portfolio
```

### 4. Install Dependencies

```bash
npm install
```

### 5. Start the Development Server

```bash
npm run dev
```

The development server will usually run at:

```text
http://localhost:5173/
```

Open the URL in your browser to view the portfolio.
